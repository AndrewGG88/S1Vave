The FM-1 firmware in your browser: the same C code that runs on the device, compiled to WebAssembly. Screen, sound, panel, all of it is the firmware's.

How to play

  • Tap a function button (press and let go, touching nothing else): its pages open. Hold it: it is a layer, the keys and knobs change job until you let go. HOME tapped while a layer is held locks it open.
  • PRESETS picks the program (32), KNOB 1-4 are the page's four parameters, SELECT the tempo, ALGORITHM the sequencer track (A / B), OCT − / + the octave.
  • HOME PERFORM page, EDIT oscillators and filter, ENV, LFO, FX chorus, delay, reverb, GLO global / voice / output, ARP the arpeggiator (on its page: HOLD).
  • Hold SEQ: the white keys are steps 1-16 (tap: set with the last note or chord, again: clear). PLAY starts the sequencer, REC records on top.
  • Hold SAVE + SEL: a new random sound. SAVE twice: keep the program (kept in this browser).

Hold a button with the mouse and play the computer keys at the same time; on a phone, use two fingers.

Computer keyboard

The letters are printed on the keys above. Two rows, like a piano:

Keys C4 .. E5Z S X D C V G B H N J M , L . ; /
Keys F3 .. B3Q 2 W 3 E 4 R
Keys F5 .. G5I 9 O
Buttons1 HOME, 5 ENV, 7 LFO, 8 ARP, 0 SEQ, - EDIT, = GLO, [ FX, ] SAVE, Enter SEL, Space PLAY, \ REC, ← → OCT − / +
Knobs↑ ↓ PRESETS; drag a knob up / down or scroll on it

The positions are those of a US keyboard; on other layouts the same physical keys play.

MIDI keyboard

Any MIDI keyboard plays it (notes with velocity, pitch bend, mod wheel, sustain, CCs, clock), as over USB on the device.

Web MIDI works in Chrome, Edge, Opera and Firefox; not in Safari.

Your programs

Saved programs, settings and sequencer patterns stay in this browser (localStorage).
